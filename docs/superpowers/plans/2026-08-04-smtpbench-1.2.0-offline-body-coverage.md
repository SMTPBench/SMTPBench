> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add three capabilities to SMTPBench, folded into the unmerged 1.2.0 branch (PR #10): a randomly-selected body-text prefix from a folder, a fully-offline EML-to-folder writer keyed by SHA-256, and a combined unit+integration coverage gate in CI.

**Architecture:** Both features follow the existing attachment machinery: a plan object built once in `main()`, stored as a module global, selected per-message with the existing seeded RNG, mutated under the single `lock`, and reset in `conftest.py`. Offline mode forks `send_email()` at the top and bypasses DNS/MX + banner check in `main()`. Coverage uses `pytest-cov` + `coverage combine` across the two CI jobs.

**Tech Stack:** Python 3.8+, stdlib `hashlib`/`email`, `pytest`, `pytest-cov`, `coverage`, ruff, GitHub Actions.

## Global Constraints

- **Version stays 1.2.0 — no bump.** Do NOT change `pyproject.toml` `version` or `smtpbench/__init__.py` `__version__`. New features append to the existing `## [1.2.0]` CHANGELOG entry.
- **Content/metadata split (invariant):** raw payload text/bytes flow only into the MIME message. Only metadata reaches logs/summary/debug/terminal. Body excerpts log filename + `char_len` only — never the excerpt text. Attachments keep their existing `content`-key stripping.
- **Credential redaction (invariant, unchanged):** credentials never reach any log/summary/debug/terminal except the single CLI-credential warning. Summary `config.auth` stays a boolean.
- **Module-global threading model is by design.** New globals (`body_plan`, `offline_mode`, `eml_out_dir`) are declared `global` in `main()`, mutated under `lock` where they interact with counters, and reset in `tests/conftest.py`'s `reset_globals` fixture in BOTH the before-yield and after-yield blocks.

- **Deterministic RNG.** Per-message selection uses the existing `random.Random(f"{run_uuid}:{thread_id}:{message_id}")` (`cli.py:748`). Body selection happens AFTER attachment selection so the call order stays fixed.
- **Ruff owns lint+format** (`E, F, I, W, UP`, `E501` ignored, line-length 100, py38, `docs/` excluded). Every task ends green on `.venv/bin/ruff check .` and `.venv/bin/ruff format --check .`.

```python
class BodyPlan:
    """Per-message body-prefix selection from a corpus of text files."""

    def __init__(self, corpus):
        self.corpus = corpus  # list of {"filename", "char_len", "content"}

    def select(self, rng):
        """Return one corpus entry chosen uniformly at random."""
        return rng.choice(self.corpus)


def build_body_plan(args):
    """Build a BodyPlan from body_text_dir, or None if the flag is absent.

    Reads every regular file as UTF-8 text (errors="replace" so one bad byte
    never aborts the run). Raises if the directory is missing or yields no files.
    """
    body_text_dir = args.get("body_text_dir")
    if not body_text_dir:
        return None
    if not os.path.isdir(body_text_dir):
        raise NotADirectoryError(f"Body text directory not found: {body_text_dir}")
    corpus = []
    for entry in sorted(os.listdir(body_text_dir)):
        full = os.path.join(body_text_dir, entry)
        if not os.path.isfile(full):
            continue
        with open(full, encoding="utf-8", errors="replace") as body_file:
            content = body_file.read()
        corpus.append({"filename": entry, "char_len": len(content), "content": content})
    if not corpus:
        raise ValueError(f"Body text directory is empty or unreadable: {body_text_dir}")
    return BodyPlan(corpus)
```

def write_eml(msg, out_dir):
    """Serialize msg and write it as {sha256}.eml into out_dir; return the hex digest.

    Content-addressed naming: identical message bytes map to one file (dedup).
    """
    raw = msg.as_bytes()
    digest = hashlib.sha256(raw).hexdigest()
    path = os.path.join(out_dir, f"{digest}.eml")
    with open(path, "wb") as eml_file:
        eml_file.write(raw)
    return digest
```

@pytest.mark.integration
def test_smtpbench_offline_eml(tmp_path):
    """Offline mode writes threads*messages SHA-named .eml files, no server."""
    out_dir = tmp_path / "eml_out"
    result = subprocess.run(
        [
            sys.executable, "-m", "smtpbench",
            "recipient=offline@example.com", "port=25",
            "threads=2", "messages=3",
            f"eml_out_dir={out_dir}",
        ],
        capture_output=True, text=True, timeout=60,
    )
    assert result.returncode == 0, f"smtpbench failed: {result.stderr}"
    eml_files = list(out_dir.glob("*.eml"))
    assert len(eml_files) == 6, f"expected 6 EML files, found {len(eml_files)}"
    for path in eml_files:
        stem = path.stem
        assert len(stem) == 64 and all(c in "0123456789abcdef" for c in stem), (
            f"filename not a sha256 hex digest: {path.name}"
        )
        # Each file parses as a MIME message carrying the run UUID header
        import email

        with open(path, "rb") as f:
            parsed = email.message_from_binary_file(f)
        assert parsed["X-SMTPBench-Run-UUID"], "missing run UUID header"
```
